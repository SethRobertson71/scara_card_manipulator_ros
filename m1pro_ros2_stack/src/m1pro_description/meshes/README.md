# Mesh Files

The STL mesh files for the Dobot M1 Pro are sourced directly from the
official Dobot ROS1 package. Clone the repository and copy the STL files here:

  git clone https://github.com/Dobot-Arm/M1Pro-ROS.git
  cp M1Pro-ROS/dobot_description/meshes/*.STL ./

Required files:
  - base_link.STL
  - Link1.STL
  - Link2.STL
  - Link3.STL
  - Link4.STL

See the setup guide for full instructions.
